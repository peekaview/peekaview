Über PeekaView

Bildschirm teilen sollte so einfach sein wie einen Link verschicken.

Das Problem

Einer Kundin eine Einstellung zeigen, einem Kollegen bei einem Fehler helfen, im Team kurz auf denselben Bildschirm schauen: Das dauert eigentlich nur Sekunden. In der Praxis heißt es oft erst Software installieren, ein Konto anlegen und Zugangsnummern am Telefon durchgeben.

Unser Ansatz

Bei PeekaView schickt die teilende Person einen Link oder einen Code aus zwei Wörtern. Zum Ansehen genügt ein Browser, ein Konto ist nicht nötig. Bild und Ton gehen direkt von Gerät zu Gerät und sind Ende-zu-Ende verschlüsselt. Wer Fernsteuerung braucht, installiert die Desktop-App.

Der Basic-Tarif ist kostenlos, auch für berufliche Nutzung. Kostenpflichtig sind nur Zusatzfunktionen, die auf unseren Servern laufen – siehe Preise.

Offener Quellcode

Der Code steht unter der AGPL und liegt offen auf GitHub. Jeder kann nachprüfen, wie PeekaView mit Daten umgeht, und zur Weiterentwicklung beitragen.

Wer dahintersteht

PeekaView wird von der in42 GmbH entwickelt. Unsere Schwerpunkte sind Webentwicklung, skalierbare IT-Infrastruktur und KI-gestützte Prozesse – vom Prototyp bis zum Betrieb.
