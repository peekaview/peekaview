Hilfe zur Einrichtung
Entwickleroptionen fehlen?

Öffne die Geräteinfos und tippe siebenmal auf „Build-Nummer“ (ggf. unter „Softwareinformationen“). Bestätige deine Bildschirmsperre.

Unter „Entwickleroptionen“ → „Debugging über WLAN“ einschalten und Androids Abfrage bestätigen. Zum Koppeln „Gerät über einen Kopplungscode koppeln“ öffnen. Den Dialog offen lassen und den Code in der PeekaView-Benachrichtigung eingeben.

Manuell koppeln

PeekaView und Einstellungen in geteilter Ansicht öffnen. Den Kopplungscode-Dialog offen lassen und Port sowie Code übernehmen.

Verbindungsport: „IP-Adresse & Port“ auf der WLAN-Debugging-Hauptseite. Dieser unterscheidet sich vom Kopplungsport.

PeekaView stellt die Verbindung beim Teilen automatisch her. Nur nach einem Handy-Neustart oder beendeter Fernsteuerung kann Android erneut „Debugging über WLAN“ verlangen. Eine gespeicherte Kopplung wird weiterverwendet.
